# ARTINUS OCR

2026-09 ARTINUS Frontend Engineer 과제 전형을 위한 React Native 모바일 앱입니다.

현재는 요구사항과 기술 선택을 논의하는 단계이며, 앱은 아직 구현하지 않았습니다.

## 구현 목표

카메라 프리뷰에서 촬영한 정지 이미지에 OCR을 실행하고, 촬영 이미지와 인식된 텍스트를 사용자가 확인할 수 있도록 합니다.

- iOS / Android에서 동일한 기능 흐름 제공
- 실기기에서 원활한 카메라 프리뷰
- OCR 처리 중 UI 반응 유지
- 저조도, 블러, 기울어진 텍스트 등 나쁜 입력에 대한 최소한의 처리
- 카메라 권한 거부, 촬영 실패, OCR 실패 및 텍스트가 없는 결과 처리
- 텍스트 수정·복사는 구현 범위에서 제외

## 확정된 조건

- 프레임워크: React Native
- iOS 검증 환경: iPhone 17 Pro
- Android 검증 환경: 에뮬레이터

아직 테스트를 수행하지 않았습니다. Android 에뮬레이터 검증으로 실제 기기의 카메라 프리뷰 성능, 메모리 및 발열 검증을 대신할 수 없으며, 실기기 검증 여부는 별도로 기록합니다.

## 앞으로 결정할 사항

- React Native 프로젝트 구성과 버전
- 카메라 및 OCR 라이브러리 조합
- OCR 엔진의 지원 언어와 알려진 한계
- 화면 상태, 비동기 작업 및 임시 이미지 관리 방식
- 나쁜 입력에 대한 처리 범위와 테스트 기준

## 실행 방법

프로젝트 구성 후 iOS / Android 빌드 및 실행 방법을 추가합니다.

## 기술 선택 및 검증 기록

구현 과정에서 주요 라이브러리와 아키텍처의 선택 이유, trade-off, 알려진 한계 및 실제 테스트 결과를 기록합니다.

## AI 도구 활용

Codex를 사용해 요구사항과 구현 방향을 논의하고 초기 저장소 문서를 작성했습니다. 앱 코드는 아직 생성하지 않았습니다.

구현 과정에서 AI가 생성한 코드를 그대로 사용한 부분, 직접 수정·검증한 부분, 제안을 기각하거나 별도로 판단한 사례를 구분해 기록합니다.
