# 구현 계획과 서브 에이전트 작업 분담

작성일: 2026-09-28

현재 OCR 서비스 인증을 기다리는 중이다. 실제 OCR 연결을 제외한 앱 기반, 카메라, 결과 화면, 비동기 흐름을 먼저 구현한다. 이 문서는 합의한 작업 계획이며 구현 완료 기록이 아니다.

## 첫 단계 완료 기준

실제로 사진을 촬영하고, 개발용 모의 OCR 응답으로 결과 확인과 오류 복구 흐름을 사용할 수 있는 상태를 만든다.

- React Native + TypeScript + Expo development build + Expo Camera로 구성한다.
- iOS·Android 빌드와 가능한 실행 검증을 수행한다.
- iPhone 17 Pro 실기기 검증은 사용자 기기 연결·조작이 필요한 단계에서 함께 진행한다.
- Android는 에뮬레이터로 검증하며 실기기 프리뷰·메모리·발열 검증과 구분한다.
- 모의 결과를 실제 OCR 결과로 오해하지 않도록 개발용 표시를 제공한다.
- 실제 OCR 품질, 자동 품질 감지 정확도, 실제 서비스 처리 시간은 인증 완료 후 검증한다.

## 1. 공통 기반과 계약 확정

메인 에이전트가 병렬 작업 전에 다음을 준비한다.

- Expo·React Native 프로젝트를 구성하고 호환되는 버전과 의존성을 고정한다.
- 촬영 작업 상태와 전환 규칙을 정의한다.
- 앱에서 사용하는 OCR 요청·응답·품질 경고·오류 타입을 정의한다.
- 모의 OCR과 실제 OCR을 교체할 연결부를 구성한다.
- 공통 실행·검증 명령을 정리한다.
- 서브 에이전트별 담당 파일 범위를 지정한다.

클라우드 제공자의 원본 응답은 연결부에서 앱의 공통 타입으로 변환한다. 서비스 인증 대기 중에는 제공자 선택을 새로 확정하거나 실제 호출 성공을 가정하지 않는다.

## 2. 독립 영역 병렬 구현

| 담당 | 작업 범위 |
| --- | --- |
| 메인 에이전트 | 작업 분담, 통합 검토, 네이티브 빌드, E2E 검증 및 기록 |
| 기반 구현 에이전트 | 공통 기반, 카메라 권한, 프리뷰, 촬영, 토치, 임시 파일 관리, 전체 흐름 연결 |
| 서브 에이전트 A | 결과 화면, 사진 확대, 품질 경고, 재시도·재촬영 UI |
| 서브 에이전트 B | 모의 OCR 시나리오, 상태 전환과 비동기 경합 테스트 |

공통 규격을 먼저 전달하고 파일 소유 범위를 나눠 충돌을 줄인다. 공통 타입·의존성·설정 변경이 필요하면 메인 에이전트와 조율한다. 서브 에이전트는 담당 변경과 검증 결과, 미검증 사항을 보고하고 메인 에이전트가 통합한다.

### 모의 OCR 시나리오

- 텍스트 인식 성공
- 텍스트 없는 결과
- 저조도·블러 등 품질 경고를 포함한 결과
- 요청 실패
- 응답 지연 및 타임아웃 처리
- 재촬영 후 이전 요청의 응답 도착

모의 품질 경고는 UI 검증용 데이터이며 실제 이미지 분석 결과가 아니다. 개발용 시나리오 선택 기능을 일반 사용자 흐름과 구분한다.

## 3. 통합과 검증

메인 에이전트가 전체 흐름을 연결하고 다음을 확인한다.

- 실제 촬영 → 모의 처리 → 사진·텍스트·품질 경고 확인
- 카메라 권한 거부와 복구 경로
- 중복 촬영·중복 요청 방지
- 처리 중 재촬영과 이전 응답 무시
- 빈 결과와 요청 실패 구분
- 같은 사진으로 재시도
- 앱 전환 시 카메라와 진행 작업 처리
- 사진 사용 종료 후 임시 파일 정리
- iOS·Android 빌드 및 가능한 환경에서 실행

테스트 코드는 최소한으로 작성하고 Maestro E2E를 우선한다. 자동 테스트는 정상 흐름, 오류 복구, 재촬영 후 이전 응답 무시처럼 실제 회귀를 잡을 수 있는 동작에 집중한다. 프리뷰·초점·발열은 자동 테스트 통과만으로 검증됐다고 판단하지 않는다.

통합 후 서브 에이전트가 요구사항 누락과 구체적인 회귀 위험을 검토한다. 메인 에이전트는 발견 사항을 확인하고 필요한 수정을 반영한다.

## 4. 인증 완료 후 실제 OCR 연결

- 사용할 OCR 서비스의 실제 호출과 지원 범위를 확인한다.
- 모의 연결부를 실제 중계 API와 연결한다.
- 자격증명은 앱에 포함하지 않고 서버에서 관리한다.
- 실제 요청·응답·오류를 공통 계약에 맞춰 변환한다.
- 정상·저조도·블러·기울어진 사진 및 문서 외 사진으로 인식과 품질 경고를 검증한다.
- 업로드부터 결과 표시까지 전체 시간을 측정한다.
- 서비스별 품질 분석 지원 차이는 스펙에 반영한다. 대체 서비스에 같은 기능이 있다고 가정하지 않는다.

## 에이전트 모델 운영 기준

- 복잡하고 큰 작업과 통합 설계: GPT-6 Astra
- 중간 규모 독립 구현: GPT-6 Sol, reasoning effort xhigh
- 단순 정리·반복 작업: GPT-6 Luna, reasoning effort max

사용자가 지정한 기준이며, 작업 크기와 파일 소유 범위를 먼저 나눈 뒤 배정한다.
