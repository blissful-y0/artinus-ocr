## 커밋 규칙

- 한 커밋이 한 기능을 끝냅니다. 중간 커밋에서도 없는 모듈을 import하지 않습니다.
- 기반 커밋에는 최소 실행 화면을 두고, 기능을 붙이는 커밋에서 완성된 화면으로 바꿉니다.
- 커밋 메시지에 무엇을 왜 바꿨는지와 어떤 검사를 통과했는지 적습니다. 통과한 검사와 돌리지 못한 검증은 구분합니다.
- 검증하다 찾은 문제는 원인과 영향 범위를 설명하는 수정 커밋으로 남깁니다.

## 커밋하지 않는 것

`.env`, 자격증명, `node_modules`, Expo가 만드는 네이티브 프로젝트(`android/`, `ios/`), 빌드·테스트 산출물은 커밋하지 않습니다. 서버의 `.env.example`과 의존성 잠금 파일, 비밀값이 없는 `apps/mobile/.env`는 포함합니다.
